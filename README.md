# Hi, I'm Iván

I am finishing a 372 ECTS double degree in Mathematics and Computer Science. My main interests are 3D computer vision and machine learning for medical data, and I am starting to research topological data analysis on biological data with a research collaboration scholarship from the Spanish Ministry of Education.

## Relevant Projects

- [3D Semantic Lifting with Gaussian Splatting](https://github.com/ivanver02/semantic-lifting-3dgs) - Research project in 3D computer vision, focused on semantic class segmentation by labelling 3D Gaussians from 2D masks. First-author preprint on [arXiv](https://arxiv.org/abs/2610.08756).

- [Hospital Gait Analysis Backend](https://github.com/ivanver02/markerless-gait-analysis-backend) - Server code for multi-camera gait analysis. It involves 3D reconstruction and ensembling 2D pose estimators.

- [Hospital Gait Analysis Frontend](https://github.com/ivanver02/markerless-gait-analysis-frontend) - Frontend that controls and synchronizes the cameras and sends the data to the server.

- [Reservoir Storage Forecasting](https://github.com/ivanver02/reservoir-data-platform) - Data pipeline for Spanish reservoirs. It cleans public records, forecasts weekly storage and plans possible transfers.
